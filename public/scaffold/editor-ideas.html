Make The Library Findable

How to name a folder so a cue can reach it.

2,371 of 2,522 clips are invisible to this board. Not missing, invisible: nothing in the path tells the matcher where it was shot or what is in it. It scores a named neighborhood higher than anything else, so a folder called 7 27 26??? lol can hold the best shot on the drive and no cue will ever surface it.

One rename at the folder level fixes every clip inside it. Three parts, in this order:

2026-07-09 Scott's Addition Listing Site Visit

Not this: 7:9:26/clips, Meta Glasses, 6:30:26, Blank Richmond Content

This: date, then the neighborhood, then what is happening in it. Plain words. The matcher reads the folder name as text, so a real sentence beats a code every time.

1
Date first, as 2026-07-09. Sortable, and it lets the board prefer a fresh clip over an old one.
2
Neighborhood, spelled out. Scott's Addition, Church Hill, Manchester, The Fan, Forest Hill. This is the highest scoring signal there is. If the shoot moved around, name the main one.
3
What is happening. Listing Site Visit, Sold Diary, Cedar Grove Reno, Client Call, Working Outdoor. Use the category names you two already built, so the cue cards and the drive speak the same language.

Then keep tagging clips into your existing categories. Right now 6% are tagged and zero clips have both a neighborhood and a category. A clip with both is the only kind a cue can find on purpose. Everything else it finds by luck.
